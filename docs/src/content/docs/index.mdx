## One task, one tab

Give each task a tab. nerdr starts your chosen agent on a branch from the
latest `main`, with a worktree in each repository the task needs, such as
a backend and a frontend. Fix a bug, build a feature and pick up an issue
at the same time, without the agents stepping on each other.
