## What you need

- **Linux or macOS**, on x86-64 or ARM64
- **git**
- **At least one coding agent** on your PATH: `claude`, `codex`, `copilot`,
  `opencode`, `cursor-agent`, `gemini` or `agy`
- **The GitHub CLI, `gh`**, signed in with `gh auth login`, for pull
  requests, CI and issues. Everything else works without it.

## Install

<Tabs>
<TabItem label="Install script">

```sh
curl -fsSL https://nerdr-dev.github.io/nerdr/install.sh | sh
```

The script downloads the latest release for your system from GitHub,
checks it against the release's `checksums.txt` and puts `nerdr` in
`~/.local/bin`. Set `NERDR_INSTALL_DIR` for another folder, and
`NERDR_VERSION=v0.1.0` for a release other than the latest:

```sh
curl -fsSL https://nerdr-dev.github.io/nerdr/install.sh | NERDR_VERSION=v0.1.0 sh
```

Run it again to update.

</TabItem>
<TabItem label="Homebrew">

```sh
brew install nerdr-dev/tap/nerdr
```

Update with `brew upgrade nerdr`.

</TabItem>
<TabItem label="Go">

With Go 1.27 or newer:

```sh
go install github.com/nerdr-dev/nerdr/cmd/nerdr@latest
```

This installs to `$(go env GOPATH)/bin`, usually `~/go/bin`.

</TabItem>
<TabItem label="Download">

Each [release](https://github.com/nerdr-dev/nerdr/releases) has an
archive per system, and `checksums.txt`:

| System | Archive |
|---|---|
| macOS, Apple silicon | `nerdr-darwin-arm64.tar.gz` |
| macOS, Intel | `nerdr-darwin-amd64.tar.gz` |
| Linux, x86-64 | `nerdr-linux-amd64.tar.gz` |
| Linux, ARM64 | `nerdr-linux-arm64.tar.gz` |

nerdr is a single static binary: unpack it into a folder on your PATH.

```sh
tar -xzf nerdr-linux-amd64.tar.gz nerdr
mv nerdr ~/.local/bin/
```

</TabItem>
</Tabs>

Check it:

```sh
nerdr version
```

## Start it

Start nerdr in the folder that holds your repositories:

```sh
cd ~/develop
nerdr
```

On first start, nerdr asks where new worktrees go (`~/worktrees-nerdr` by
default), where it may install its skills and hooks for the agents, and
where it keeps its notes. All of this can be changed later; see
[Configuration](../../configure/configuration/).

## Build from source

<Steps>

1. With git and Go 1.27 or newer, clone the repository and install the
   binary:

   ```sh
   git clone https://github.com/nerdr-dev/nerdr && cd nerdr
   make install          # installs to $(go env GOPATH)/bin, usually ~/go/bin
   ```

2. Make sure `$(go env GOPATH)/bin` is on your PATH, then check with
   `nerdr version`.

</Steps>

`make all` builds the four binaries in `dist/` for other machines.

## On macOS

- nerdr is not signed. The install script, Homebrew and `go install` are
  not stopped by Gatekeeper, but an archive downloaded in a browser may
  be. Remove its quarantine flag with `xattr -d com.apple.quarantine nerdr`.
- A Mac laptop may need `fn` for F1–F5. Use `ctrl+q e 1`…`e 5` instead,
  or `m` in the review panel to cycle its screens, and set
  `function_keys = false` to show those shortcuts in menus.
