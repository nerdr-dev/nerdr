The review panel holds what you need besides the agent: its changes,
GitHub, tasks, skills, the history of nerdr's messages and plugins. Each
but the plugins is a screen with an F-key, a dialog over the window. The
code changes can also be panes of the tab, and the plugins always are,
beside its agents and terminals: as many of each as you like.

## Opening and closing

While the panel is closed, the agent has the whole window.

- **F1 code changes** opens as a dialog, for a look at the diff now and
  then. Press `ctrl+q t c` in it to keep it open beside the agent: it
  goes in a pane of the tab's. Elsewhere, `ctrl+q t c` opens the code
  changes in a new pane.
- **Plugins** have no F-key: `ctrl+q t p` opens them in a pane of the
  tab's, so you can use a plugin's screen while you talk to the agent.
- **+changes** and **+plugins**, with the buttons for new panes
  (+terminal, +agent, +review), open another pane of the code changes or
  the plugins. Each pane is a panel of its own: its own repository,
  file, diff and scroll, or its own plugin. Two of a kind are numbered,
  `changes 2`.
- The panes are the tab's, as its terminals are: `−` and `×` in their
  frames, or `ctrl+q t m` and `t x`, minimise and close them; `tab` and
  `ctrl+q t ←` / `t →` go to them, the minimised ones too; drag the
  divider to change their width. When the tab has a changes pane, F1
  goes to it, and pressed there, back to the agent; `ctrl+q t p` does
  the same for the plugins pane.
- **F2 GitHub**, **F3 tasks**, **F4 skills** and **F5 history** open as a
  dialog over the window, leaving the agent its size underneath. `esc`,
  `q`, the same F-key again or a click outside closes it. A dialog has
  `×` too.

`F1`–`F5` open and focus a screen; `ctrl+q g c`, `g g`, `e`, `k` and `h` do the same, and
`m` in the panel cycles the screens. `ctrl+q a a` or a click gives the
keyboard back to the agent. Press `?` in the panel for all of its
commands.

| After `ctrl+q` | Action |
|---|---|
| `g c`, `g g`, `e`, `k`, `h` | Open code changes, GitHub, tasks, skills or history (F1…F5) |
| `t c` | The F1 dialog in a pane; else the code changes in a new pane |
| `t p` | The tab's plugins pane, opening one if there is none; in it, the plugin list or a running plugin's screen |

<details>
<summary>F-keys in terminals and on Mac laptops</summary>

In a terminal pane at its prompt, F1–F5 still switch screens. A
full-screen program there (htop, mc, vim) gets the function keys for
itself: use `ctrl+q g c` (F1), `g g` (F2), `e` (F3), `k` (F4) and `h` (F5) then. F6 and up always go to the program.

A Mac laptop may need `fn` for the F-keys. Set `function_keys = false`
to label the screens with their `ctrl+q` shortcuts instead.

</details>

## Asking the agent from the panel

Requests from the panel go to the tab's agent as messages, delivered when
it is idle. Most open as drafts for you to read, edit and send.

Read drafts before sending. Review comments and CI logs contain text from
others, which may include instructions meant for the agent, and the agent
acts within its permissions.
