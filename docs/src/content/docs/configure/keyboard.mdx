Typing goes to the agent. Press **`ctrl+q`**, then a command key, to
control nerdr. Wait a moment after the prefix and a box in the middle of
the screen shows every key, the most used first; turn it off with
`prefix_hint = false`. `ctrl+q ?` finds any command by name or description.

<Aside>
The prefix can be any `ctrl+<letter>`; set `prefix` in the config. `ctrl+q i`
sends a `ctrl+q` to the agent.
</Aside>

## Main keys

| After `ctrl+q` | Action |
|---|---|
| `c` / `x` | Create / close tab |
| `C` | New tab on a branch on top of this tab's |
| `→` / `←` | Next / previous tab, or repository on the group row |
| `↓` / `↑` | Move to the tab row / group row |
| `1`…`9`, `0` | Go to a tab in the group; `0` the last |
| `]` / `[` | Next / previous repository |
| `w` / `n` | Open the waiting list / go to the next waiting agent |
| `f` / `space` | Find a tab by name across groups |
| `r` | Rename tab |
| `shift+←` / `shift+→` | Move tab left / right; repeat without the prefix |
| `m` / `M` | Queue a task for one / several tabs |
| `e` | Tasks waiting for the agent (F3) |
| `k` | The agents' skills (F4) |
| `h` | History: everything nerdr has said in its bar (F5) |
| `v` | The global plugins, one for all tabs, in a dialog (`t p` in it goes between the list and a plugin's screen) |
| `p` | Pick a [saved prompt](../../panel/tasks/#saved-prompts) for the agent |
| `tab` | Next pane, the minimised ones too, then the split's other tab |
| `<` / `>` | Widen / narrow the right side of a split; `,` / `.` also work |
| `o` | Open the worktree in `worktree_editor`, or VS Code |
| `b` / `PgUp` | Scroll the agent's output; `q` ends it |
| `?` / `:` | Find a command by name or description |
| `s` | Settings |
| `u` | Usage and rate limits |
| `/` | Search the agents' conversations |
| `d` | Machines: this machine and the [servers](../../use/remote/#several-machines-in-one-nerdr); add, connect again, disconnect, remove |
| `j` | Programs in no tab: those from before nerdr's core started again that no tab took up; stop one or all |
| `q` | Close or quit: Close (`enter`) leaves the agents and other programs running, to connect to again; Quit (`q`) stops them, on every machine the dialog names, and tabs come back at the next start; with servers too, Quit here (`l`) stops only this machine's and leaves the servers' working. With `NERDR_HOLDER=0`, quit |
| `i` | Send `ctrl+q` to the agent |
| `esc` | Cancel; in a command group, back to the main keys |

In a dialog for no tab, such as a new tab, search or settings,
`ctrl+o` moves it to the [next machine](../../use/remote/#which-machine-a-dialog-is-for).

The prefix stays active while you move between tabs: `ctrl+q → → x`
closes the tab two places right. See
[Moving between tabs](../../use/tabs/#moving-between-tabs).

## Command groups

Four groups use two keys, marked › in the box. Their key shows the group's
commands in the box instead, and `esc` or backspace goes back; repeating the
group key runs its main command.

### Agent: `a`

| After `ctrl+q` | Action |
|---|---|
| `a a` | Give the agent the keyboard |
| `a n` | Edit the tab's note |
| `a w` | What happened since your last visit |
| `a h` | List the prompts you sent the agent, the latest first |
| `a s` | Switch agents in the same worktree, with a handoff |
| `a m` | [Move the tab to another machine](../../use/remote/#moving-a-tab-to-another-machine) |
| `a r` | Restart and resume the conversation |
| `a c` | Code review of the agent, as `t r` |
| `a x` | Stop the review of the agent |

### Panes: `t`

| After `ctrl+q` | Action |
|---|---|
| `t t` | New terminal |
| `t a` | New agent in the same worktree |
| `t c` | The F1 dialog in a pane; else the code changes in a new pane |
| `t p` | The tab's plugins pane, opening one if there is none; in it, the plugin list or a running plugin's screen |
| `t r` | New code review of the agent whose pane has the keyboard |
| `t x` | Close the pane |
| `t m` | Minimise the pane, or show it again |
| `t ←` / `t →` | The pane on the left / right |
| `t ⇧←` / `t ⇧→` | Move the pane left / right; `enter` ends |

### Git/GitHub: `g`

| After `ctrl+q` | Action |
|---|---|
| `g g` | This branch: changes, pull request and CI, in F2 |
| `g c` | Code changes (F1) |
| `g p` | Your open pull requests across these repositories, starting at the tab's own |
| `g b` | Open the tab's pull request in your browser |
| `g r` | Add repositories to the tab, or take them away |
| `g o` | Issues assigned to you across these repositories |
| `g l` | git and `gh` calls per tab, and any permission errors (for example, when running nerdr in a sandbox) |

### Layout: `l`

| After `ctrl+q` | Action |
|---|---|
| `l v` | Two tabs side by side |
| `l s` | Swap the sides of a split |
| `l d` | Show / hide tab details |
| `l b` | Show / hide the group row |
| `l g` | Show / hide the bottom bar |
| `l t` | Tabs on top or on the left |
| `l m` | Compact sidebar with only status lights |

## In the review panel

`F1`–`F5` open a screen, and `ctrl+q t p` the plugins; `?` in the panel
lists all its keys. The keys of each screen are on its page:
[F1](../../panel/code-changes/), [F2](../../panel/github/),
[F3](../../panel/tasks/), [F4](../../panel/skills/),
[F5](../../panel/history/), [plugins](../../panel/plugins/).

## Mouse

- **Tabs:** click a group or tab to select it, middle-click a tab to
  close it, and scroll over the bars to move. Right-click a tab for its
  actions, or a group to create a tab in it. `+` after the tabs creates a
  worktree in the repository; `+` after the groups opens the repository
  picker.
- **Commands:** `? commands` at the right of the bar opens the command
  palette: every command, with its shortcut, to search and run.
  Right-clicking the agent opens it too.
- **Hints:** hover over lights, tabs and badges for what they mean.
- **Panes:** click a pane to give it the keyboard, scroll to see earlier
  output, drag to select and copy. `+terminal`, `+agent` and `+review`
  open a pane; `−` and `×` in its frame minimise or close it. Drag the
  divider between panes, or between the agent and the panel, to resize;
  right-click it to share evenly.
- **Review panel:** click an F-key to open a screen. Drag over lines of a
  diff to copy their code.
- **Dialogs:** click entries, and the buttons along the bottom.

### Copying text

Dragging copies the selection when you let go, through the terminal's
OSC 52 clipboard support, so it works over SSH too.
Terminals without OSC 52, such as GNOME Terminal and Terminal.app, need a
local clipboard tool instead: `pbcopy` on macOS, and `xclip`, `xsel` or
`wl-clipboard` on Linux.

If an agent uses the mouse itself, its own selection copies as usual, or
hold `shift` to select through nerdr (if your terminal does not take
`shift`-drag for its own selection).
A program's own copy (OSC 52), such as a selection in an agent that has
the mouse or its copy command, reaches your clipboard only from the pane
with the keyboard, and only within two seconds of you clicking in it or
typing to it. Anything else a program prints to set the clipboard, from
another pane, unasked, or when the mouse only moved over it, is
discarded.

Set `mouse = false` to leave the mouse to the terminal.
